# Wyre для Android

Нативная оболочка (WebView) над веб-приложением Wyre — аналог Windows-приложения
из `desktop/`. Весь интерфейс, чаты, звонки и вложения работают на сайте Wyre;
приложение добавляет установку на телефон, разрешения камеры/микрофона, выбор
файлов и аккуратный офлайн-экран.

## Что внутри

- При первом запуске — экран настроек: адрес сервера (например,
  `https://192.168.1.7:3000`) и галка «Доверять самоподписанному сертификату»
  для локального сервера. Настройки хранятся в SharedPreferences.
- Звонки: системные разрешения камеры и микрофона выдаются при запуске,
  WebView отдаёт их сайту по запросу (`onPermissionRequest`).
- Вложения: выбор файла через системный пикер (`onShowFileChooser`),
  скачивание — через системный DownloadManager.
- Офлайн: вместо системной ошибки — спокойный экран «Ждём соединение» с
  кнопками «Повторить» и «Настройки подключения».
- Назад: работает как в браузере внутри мессенджера; двойное нажатие — выход.
- Минимальная версия Android 7.0 (API 24), целевая — Android 14 (API 34).
  APK подписан собственным ключом `wyre.keystore` (пароль `wyre-family`,
  хранится в этом каталоге — семейный проект).

Честное ограничение: фоновых push-уведомлений нет — для них нужен Firebase
(FCM). Уведомления приходят, только когда приложение открыто (живое
Socket.IO-соединение сайта).

## Сборка

Требуется один раз (уже настроено в этом каталоге):

- JDK 17: `C:\Program Files\Microsoft\jdk-17.0.19.10-hotspot`
- Android SDK: `D:\wyre\android-sdk` (cmdline-tools, platform 34,
  build-tools 34.0.0, platform-tools; `local.properties` указывает путь)
- Gradle 8.9: `D:\wyre\android-tools\gradle-8.9`
- dl.google.com из этой сети недоступен, поэтому зависимости качаются с
  зеркала Aliyun (`settings.gradle`), а SDK ставился через
  `android-sdk/mirror-proxy.cjs` с зеркала Tencent.

Пересборка APK:

```bash
cd D:\wyre\mobile-android
build.cmd            # или: npm run android:dist из корня проекта
```

Готовый файл: `dist/Wyre-1.0.0.apk`. Обновление версии — `versionCode` и
`versionName` в `app/build.gradle`.

Иконки пересоздаются командой `npm run icons` (здесь) — генератор растеризует
логотип Wyre без внешних зависимостей.
